Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun — one line, max 280 characters.

## Entry

> I asked an AI to write my eulogy and it said, 'As a language model, I cannot attend your funeral, but I can generate a tasteful absence.'

## Run

```sh
node main.ts
```

`main.ts` writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), self-checks the 280-character gate, and verifies the output by reading it back.
